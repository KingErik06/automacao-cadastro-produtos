# 🤖; Automação de Cadastro de Produtos.

Automação desenvolvida em Python e PyAutoGUI para realizar o cadastro de produtos automaticamente em um sistema web, com integração a planilhas utilizando Pandas (em breve).

## 🤖; Tecnologias.

- Python;
- PyAutoGUI;
- Pandas (em breve).

## 🤖; Objetivo.

O objetivo dessa automação é facilitar o processo de cadastro de produtos em sistemas web, tornando mais rápido um processo que pode ser demorado e repetitivo.

## 🤖; Funcionalidades.

- Abre o navegador automaticamente;
- Acessa o sistema e realiza o login automaticamente.

## 🤖; Próximas Etapas.

- Cadastro automático de produtos;
- Leitura dos produtos através de uma planilha;
- Manipulação dos dados com Pandas;
- Tratamento de erros e outras melhorias.
